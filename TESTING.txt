2026-11-09 | Drive Beyond Horizons Steam build 26437602 / Unreal 5.2.1

Automated checks (final source)
- All bundled Lua sources compile.
- 1,000 deterministic dead-end planner cases and 200 deterministic forward-connection cases pass, including geometry, native POI eligibility/weights, endpoint direction, JSON round trips and lower-density subset selection.
- Native adapter checks cover borrowed-struct lifetime, native parameters and transforms, stable POI identity, host-only registration and the inverse native LevelSpawn slider mapping.
- Network checks cover version/session mismatch, complete host plan transfer including banking and signs, resend after culling, host-withheld roads and replacement of guest geometry after a host terrain refit.
- Surface checks cover hills between nodes and across the road width, bounded elevation repair, static obstacles and incremental validation. Native calls run on the registered game-thread Lua state, never a Lua coroutine.

Root causes and limits of diagnosis
- Source inspection found that the previous road height influencer could change terrain beneath existing objects, while removing a road removed that influence. This version follows sampled terrain and disables height influence.
- Generated native foliage was being mistaken for solid terrain obstructions. The terrain sampler now recognizes only native landscape meshes as ground; accepted corridors clear only native SLLandscapePCG instances. Ordinary structures, POI actors and player objects are preserved.
- The in-progress validator used a Lua coroutine, which UE4SS rejected for native calls and consequently withheld roads. Explicit game-thread work cursors replaced it.
- The validator could run before POI registration settled and prevent a pending road from ever becoming ready. Readiness, final terrain fitting and visibility now follow that order; blocked routes can retry safely.
- These findings explain observed failure mechanisms, not every possible floating object in every seed or mod combination.

Performance evidence
- On the same isolated host/branch, narrowing the repeated native-foliage scan reduced two empty cleanup measurements from 1,583/2,167 ms to 92/65 ms. This is CPU time for one cleanup operation, not whole-game frame time or FPS.
- Repeated maintenance uses bounded batches. Native level descriptors are registered together to reserve spacing; the native proximity streamer controls loaded POI actors. No FPS improvement is claimed.

Multiplayer
- Automated transport/geometry consistency checks pass. The 0.1.1 localhost guest join attempted from both an affected save and a freshly initialized solo world returned to the menu. Therefore live 0.1.1 host/guest reconstruction and Steam matchmaking are NOT verified by this run.
- The earlier 0.1.0 localhost success is not presented as 0.1.1 evidence. The QA socket adapter is absent from all deliverables.
- Use identical 0.1.1 versions on host and guests. A real host/guest drive, reconnect, save reload and distant POI streaming test remain required before treating multiplayer as release-validated.

Packaging and isolation
- Deliverables contain only BeyondDetours source/runtime files and documentation. No native game artwork, loader binaries, other mods, QA dispatchers, QA socket DLL, personal saves or generated route caches are included.
- Existing 0.1.0 release archives are retained. No public release is published or replaced.
- Beyond Mod Manager recognized the independent 0.1.1 identity with UE4SS as its only dependency. Install/reinstall tests passed, preserving the route-state fixture and leaving an unrelated mod fixture unchanged. The user's production installation is unchanged; the ZIP is ready for manual installation or manager import.
- All 1,133 non-changing entries from the earlier 1,137-file other-mod/loader inventory still match. Four other-mod runtime state files had already changed on November 8, before this resumed work; they were left untouched. Other mods' source, configuration and installations were not edited.

Remaining playtests
- Extended driving over junction seams, round tips and construction endings with different vehicles.
- Additional terrain/biome/LOD combinations, long-distance streaming and naturally occurring route ratios at different slider settings.
- Multiplayer and combinations with other mods, which were deliberately excluded from the isolated game directories.
